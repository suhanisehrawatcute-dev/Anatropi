# Anatropi

A choice-based game where you play as Elera and try to get through a problem she faces.

## Description

Anatropi is an interactive, story-driven game where you play as Elera, an orphan navigating her town. Each choice you make reflects who you are, which is the main theme of this game. 

## Features

- Interactive storytelling: Progressing through a story by making decisions
- Multiple ways to reach the end
- Character-driven narrative
- Moral dilemma
- Moving a player
- Overlapping certain things causes actions

## Getting Started

### Dependencies

- A web browser.
- A code editor if you want to view or edit the source code.

### Installing

1. Clone the project repository.
2. Extract the project files if they were downloaded as an archive.
3. Ensure that the HTML, CSS and JavaScript files are all present in the project folder.
4. Check that the file paths in the HTML document correctly link to the CSS and JavaScript files.

### Executing the Program

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Read the opening introduction to Anatropi.
4. Click the dialogue arrows to progress through the story.
5. Make choices when shown.
6. Continue following Elera's journey and discover how your decisions shape the story.

## Help

- **The characters or backgrounds do not appear:** Check that the CSS file is linked correctly and that image paths are valid.
- **The dialogue does not progress:** Check that the JavaScript file is linked correctly and that the relevant HTML elements have matching IDs or classes.
- **The choices do not appear:** Check that the choice container exists in the HTML and that the JavaScript correctly references it.
- **The styling is missing:** Check that the CSS file is linked correctly in the HTML document.
- **The fortune teller's note is not working:** Check that the HTML and CSS are linked correctly and the names are the same.
- **Something doesn't work:** Check the browser console for JavaScript errors. And remember, do not trust yourself!! Your perfect edits are the exact reason. :)
